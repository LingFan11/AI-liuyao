## 一、反吟章

### 1.1 反吟基本定义

**原文**：
卦有卦变，爻有爻变。卦变者，内外动而反吟，同一卦也。如：乾变坤

**卦象示例**：
```
乾宫：乾为天（六冲）        坤宫：坤为地（六冲）
-----------------------------------------
父母壬戌土  ━━━ 世  ○→  子孙癸酉金  ━ ━ 世
兄弟壬申金  ━━━     ○→  妻财癸亥水  ━ ━
官鬼壬午火  ━━━     ○→  兄弟癸丑土  ━ ━
父母甲辰土  ━━━ 应  ○→  官鬼乙卯木  ━ ━ 应
妻财甲寅木  ━━━     ○→  父母乙巳火  ━ ━
子孙甲子水  ━━━     ○→  妻财乙未土  ━ ━
```

**现代白话解释**：
反吟有两种情况：
1. **卦变反吟**：整个卦发生变化，内外卦都动而形成反吟，变成同一个卦。如乾卦六爻全动变成坤卦。
2. **爻变反吟**：某一爻或多爻发动变化形成反吟关系，但不是同一个卦。

**反吟的特点**：
- 主事情反复、进退两难
- 内外动荡、变化不定
- 谋事多阻、难以顺遂

### 1.2 反吟四种类型

根据反吟发生的位置和范围，分为四种类型：

#### 1. 卦变反吟（全卦反吟）

**原文**：卦变者，内外动而反吟，同一卦也。如：乾变坤

**定义**：六爻全动，内外卦都发生变化，形成反吟卦，变成同一卦。

**示例**：乾为天六爻全动 → 坤为地（乾变坤）

**特点**：变化最剧烈，主大反复、大变动。

---

#### 2. 爻变反吟（非同一卦）

**原文**：爻变者，内外动而反吟，非同一卦也。如：升变观

**卦象示例**：地风升变风地观
```
震宫：地风升                乾宫：风地观
-----------------------------------------
官鬼癸酉金  ━ ━     ×→  兄弟辛卯木  ━━━
父母癸亥水  ━ ━     ×→  子孙辛巳火  ━━━
妻财癸丑土  ━ ━ 世  ×→  妻财辛未土  ━ ━ 世
官鬼辛酉金  ━━━ 应  ○→  兄弟乙卯木  ━ ━
父母辛亥水  ━━━     ○→  子孙乙巳火  ━ ━
妻财辛丑土  ━ ━     ○→  妻财乙未土  ━ ━ 应
```

**特点**：内外卦都发动形成反吟，但变成不同的卦，主反复变化。

---

#### 3. 外卦反吟（上卦反吟）

**原文**：又有外卦反吟，而内卦不动者。如：观变坤

**定义**：外卦（上三爻）发生反吟，内卦不动。

**卦象示例**：风地观变坤为地
```
乾宫：风地观                坤宫：坤为地（六冲）
-----------------------------------------
妻财辛卯木  ━━━     ○→  兄弟癸酉金  ━ ━ 世
官鬼辛巳火  ━━━ 世  ○→  子孙癸亥水  ━ ━
父母辛未土  ━ ━     ○→  父母癸丑土  ━ ━
妻财乙卯木  ━ ━ 应      妻财乙卯木  ━ ━ 应
官鬼乙巳火  ━ ━          官鬼乙巳火  ━ ━
父母乙未土  ━ ━          父母乙未土  ━ ━
```

**特点**：外事反吟，主外部环境变化、外事反复。

---

#### 4. 内卦反吟（下卦反吟）

**原文**：又有内卦反吟，而外卦不动者。如：巽变观

**定义**：内卦（下三爻）发生反吟，外卦不动。

**卦象示例**：巽为风变风地观
```
巽宫：巽为风（六冦）        乾宫：风地观
-----------------------------------------
兄弟辛卯木  ━━━ 世      兄弟辛卯木  ━━━
子孙辛巳火  ━━━          子孙辛巳火  ━━━
妻财辛未土  ━ ━          妻财辛未土  ━ ━ 世
官鬼辛酉金  ━━━ 应  ○→  兄弟乙卯木  ━ ━
父母辛亥水  ━━━     ○→  子孙乙巳火  ━ ━
妻财辛丑土  ━ ━     ○→  妻财乙未土  ━ ━ 应
```

**特点**：内事反吟，主内部事务反复、家内不安。

### 1.3 反吟吉凶总论

**原文**：
一、反吟。
内卦反吟，内则不安；外卦反吟，外则不宁；内外反吟，内外不安之象。皆主成而败、败而成，有而即无、无而即有，得而失、失而得，来而去、去而来，散而聚、聚而散，动而思静、静而思动。

占功名，用爻旺相，迁而又迁，升往他处，仍复升来。用神失陷，或降或升，或得或失。占财物，聚散不常，买卖经营，兴废往来不定。占坟茔宅舍，欲迁不迁，或迁之而再迁，或目下就有迁移之事。占已经久远之事，目前即有变动。占天时，晴而即雨，雨而又晴。占婚姻，反复难成。占疾病，愈而又病。占盗贼、官非，见而又见。占出行，行至中途而亦反，即使到彼，而事无成。占行人，外卦反吟者，用神旺相必归，不然亦移他处。居外之人而占家宅者，内卦反吟，家庭人口不安。占彼此之形势者，内卦反吟，我乱他定；外卦反吟，他乱我定。

以上用神旺相，不变冲克者，虽则反伏，事亦必成，只恐用神化回头之冲克者，即如卦变，大凶之象。

**现代白话解释**：

**反吟总特征**：
- **内卦反吟**：内则不安，家内反复
- **外卦反吟**：外则不宁，外事不顺  
- **内外反吟**：内外都不安，全面动荡

**反吟主事**：成而败、败而成，有而即无、无而即有，得而失、失而得，来而去、去而来，散而聚、聚而散，动而思静、静而思动。

**各占事应验**：
1. **占功名**：用爻旺相，迁而又迁，升往他处又复升来；用神失陷，或降或升，或得或失
2. **占财物**：聚散不常，买卖经营兴废往来不定
3. **占坟墓宅舍**：欲迁不迁，或迁之而再迁，或目下就有迁移之事
4. **占久远之事**：目前即有变动
5. **占天时**：晴而即雨，雨而又晴
6. **占婚姻**：反复难成
7. **占疾病**：愈而又病
8. **占盗贼官非**：见而又见
9. **占出行**：行至中途而返，即使到彼也事无成
10. **占行人**：外卦反吟，用神旺相必归，不然亦移他处
11. **占家宅**（居外之人）：内卦反吟，家庭人口不安
12. **占彼此形势**：内卦反吟我乱他定，外卦反吟他乱我定

**重要原则**：
用神旺相，不变冲克者，虽则反吟，事亦必成。只恐用神化回头之冲克者，即如卦变，大凶之象。

### 1.4 反吟实战卦例

#### 例一：占随官上任（内卦反吟）

**如：卯月壬申日（旬空：戌亥），占随官上任，得"比之井"**

**本卦：坤宫水地比（归魂）**
```
白虎  妻财戊子水  ━ ━ 应
螣蛇  兄弟戊戌土  ━━━
勾陈  子孙戊申金  ━ ━
朱雀  官鬼乙卯木  ━ ━ 世  ×→
青龙  父母乙巳火  ━ ━     ×→
玄武  兄弟乙未土  ━ ━     ×→
```

**变卦：震宫水风井（游魂）**
```
妻财戊子水  ━ ━ 应
兄弟戊戌土  ━━━
子孙戊申金  ━ ━ 世
子孙辛酉金  ━━━
妻财辛亥水  ━━━
兄弟辛丑土  ━ ━
```

**解析**：
- 占随官上任：以世爻为用
- 世爻：官鬼卯木持世
- 动爻：官鬼卯木、父母巳火、兄弟未土三爻发动
- 反吟：内卦三爻全动，为内卦反吟

**断曰**：世临官星，值月建而旺，必能随往，但内卦反吟，定有反复，又不宜世爻绝于申日，复又化回头冲克，主此行不吉，不去为上。后因官掣签，所得之缺近贼营，辞而不去。及至官赴任后，忽因他故，仍行随往。至七月，贼破城，与官一同被害。与官同被害者，世爻与官鬼同受酉金之冲克也，已辞而复去者，卦得反吟之故也。

**现代白话解释**：
1. **世爻旺相**：世爻官鬼卯木值月建而旺，本可随官上任。
2. **内卦反吟**：但内卦三爻全动形成反吟，定有反复。
3. **世爻受克**：世爻绝于申日，又化回头冲克（卯木化酉金），此行不吉。
4. **断定凶险**：不去为上。后因官掣签所得之缺近贼营，辞而不去。
5. **应验准确**：后来因故又随官上任，至七月贼破城，与官一同被害。辞而复去是反吟之故，与官同被害是世爻官鬼同受酉金冲克之故。

**【按】** 此卦内卦反吟，主内事反复。占官虽吉，但有辞而复职之象，正应反吟"去而复、复而去"之理。

#### 例二：占升迁（外卦反吟）

**如：卯月己亥日（旬空：辰巳），占升迁，得"临之中孚"**

**本卦：坤宫地泽临**
```
勾陈  子孙癸酉金  ━ ━     ×→
朱雀  妻财癸亥水  ━ ━ 应  ×→
青龙  兄弟癸丑土  ━ ━
玄武  兄弟丁丑土  ━ ━
白虎  官鬼丁卯木  ━━━ 世
螣蛇  父母丁巳火  ━━━
```

**变卦：艮宫风泽中孚（游魂）**
```
官鬼辛卯木  ━━━
父母辛巳火  ━━━
兄弟辛未土  ━ ━ 世
兄弟丁丑土  ━ ━
官鬼丁卯木  ━━━
父母丁巳火  ━━━ 应
```

**解析**：
- 占升迁：以官鬼爻和世爻为用
- 世爻：官鬼卯木持世
- 动爻：子孙酉金、妻财亥水两爻发动
- 反吟：外卦两爻动（酉金化卯木、亥水化巳火），外卦反吟

**断曰**：世临卯木，月建之官，又长生于亥日。世与官星同临旺地，许之即升。果于本月由江西升任山东，未及一载，复任江西。应本月升者，卯官而值月令也；升山东者，官临卯木也；复任江西者，外卦反吟，去而复反也。

**现代白话解释**：
1. **世官旺相**：世爻官鬼卯木值月建，又长生于亥日，世与官星同临旺地，即可升迁。
2. **外卦反吟**：但外卦反吟，主外事反复、去而复返。
3. **应验精准**：果然本月由江西升任山东，但未及一年又复任江西。
4. **应期分析**：本月升是因为卯木官星值月令；升山东是官临卯木方位；复任江西是外卦反吟"去而复反"。

**【按】** 外卦反吟，主外事反复。占升迁虽得升山东，但不久复还江西，正是反吟"去而复返"之象。李我平评此二卦：临之中孚，世官得地，虽反吟，官连迁转。教人之法，何等透彻明快。

## 二、伏吟章

### 2.1 伏吟基本定义

**原文**：
二、伏吟。伏吟卦者，有内外伏吟，如无妄变大壮

**卦象示例**：天雷无妄变雷天大壮
```
巽宫：天雷无妄（六冲）    坤宫：雷天大壮（六冲）
-----------------------------------------
妻财壬戌土  ━━━     ○→  妻财庚戌土  ━ ━
官鬼壬申金  ━━━     ○→  官鬼庚申金  ━ ━
子孙壬午火  ━━━ 世  ○→  子孙庚午火  ━━━ 世
妻财庚辰土  ━ ━     ×→  妻财甲辰土  ━━━
兄弟庚寅木  ━ ━     ×→  兄弟甲寅木  ━━━
父母庚子水  ━━━ 应  ○→  父母甲子水  ━━━ 应
```

**现代白话解释**：
伏吟是指卦中动爻变化后，变爻与本爻相同，形成"伏吟"状态。伏吟分为：
1. **内伏吟**：内卦（下三爻）伏吟
2. **外伏吟**：外卦（上三爻）伏吟
3. **内外伏吟**：内外卦都伏吟（全卦伏吟）

**伏吟的特点**：
- 主迟滞不动、停滞不前
- 事情难有进展、拖延
- 如同趴伏不动、难以起身

### 2.2 伏吟吉凶辨析

**原文**：
内外伏吟者，内外忧郁呻吟之象。又有内卦动变伏吟，则内呻吟；外卦动变伏吟，则外不宁。

占名者，久困宦途，淹留仕路；占利者，财源耗散，本利消乏；占坟墓宅舍，欲迁而不能，守之而不利；占婚姻，忧而不乐；占疾病，久病呻吟；占口舌官非，事难归结；占出行，艰于动转；占行人，在外忧愁；占彼此之形势者，内卦为我，外卦为他，内伏吟，我心不开；外伏吟，他意不安。

**按**：伏吟较之反吟，反吟有冲有克，用神受克，得祸匪轻。伏吟之卦，用神旺相，冲开之年月，其志则伸；用神休囚，冲开之年月，忧郁而已。

**现代白话解释**：

**伏吟总特征**：
- **内外伏吟**：内外忧郁呻吟之象
- **内卦伏吟**：内呻吟，我心不开
- **外卦伏吟**：外不宁，他意不安

**各占事应验**：
1. **占功名**：久困宦途，淹留仕路
2. **占财利**：财源耗散，本利消乏
3. **占坟墓宅舍**：欲迁而不能，守之而不利
4. **占婚姻**：忧而不乐
5. **占疾病**：久病呻吟
6. **占口舌官非**：事难归结
7. **占出行**：艰于动转
8. **占行人**：在外忧愁
9. **占彼此形势**：内伏吟我心不开，外伏吟他意不安

**伏吟与反吟对比**：
- **反吟**：有冲有克，用神受克，得祸匪轻
- **伏吟**：用神旺相，冲开之年月其志则伸；用神休囚，冲开之年月忧郁而已

伏吟较反吟轻一些，关键看用神旺衰。

### 2.3 伏吟实战卦例

#### 例一：占父外任平安否

**如：申月癸巳日（旬空：午未），占父外任平安否，得"姤之恒"**

**本卦：乾宫天风姤**
```
白虎  父母壬戌土  ━━━     ○→
螣蛇  兄弟壬申金  ━━━     ○→
勾陈  官鬼壬午火  ━━━ 应  ○→
朱雀  兄弟辛酉金  ━━━
青龙  子孙辛亥水  ━━━
玄武  父母辛丑土  ━ ━ 世
```

**变卦：震宫雷风恒**
```
父母庚戌土  ━ ━ 应
兄弟庚申金  ━ ━
官鬼庚午火  ━━━
兄弟辛酉金  ━━━ 世
子孙辛亥水  ━━━
父母辛丑土  ━ ━
```

**解析**：
- 占父亲外任平安：以父母爻为用神
- 用神：父母戌土发动
- 动爻：父母戌土、兄弟申金、官鬼午火三爻发动
- 伏吟：外卦三爻动化伏吟（戌化戌、申化申、午化午）

**断曰**：巳火日辰生父母，当主在任平安。但外卦伏吟，为不宁之象，在任必有不得意事以呻吟也。彼问：闻地方苗獞之变，可有防碍否？余曰：日建生父，他事无虞。又问：何时归来？余曰：伏吟欲归而不能，辰年可盼。

**实际应验**：后知苗獞作崇，地方不宁，惊险异常。寅年占卦，辰年裁缺而归，午年又补西蜀（四川）。应辰年者，戌父化戌父，冲开戌父之年也。应裁缺者，巳日冲起亥水，暗动以克官也。应午年又补官者，占时遇巳日，拱起午火之官，当日亥水克之而不尽，今年火官星值年，依然旺也。

**现代白话解释**：
1. **父母得生**：巳火日辰生父母戌土，父亲在任平安。
2. **外卦伏吟**：但外卦三爻全动化伏吟，主外事不宁，在任有不得意事。
3. **应验准确**：果然地方苗獞作乱，惊险异常，欲归而不能（伏吟之象）。
4. **应期辨析**：辰年裁缺归来（冲开戌土），午年又补官（午火官星值年）。

**【按】** 外卦伏吟，主外事停滞不前。虽然父亲平安，但被困任所，欲归不能，正是伏吟"滞而不动"之象。

**李我平评论**：

李我平曰：《易林补遗》有曰，爻有伏吟不吉，术者未闻，卦有反吟最凶，卜家谁觉？是不看用神之衰旺，竟以反伏为畏途也。今野鹤此论，以比之井卦，世逢冲克，事反伏，身受其殃。临之中孚，世官得地，虽反伏，官连迁转。教人之法，何等透彻明快。

**现代白话解释**：
李我平评论说：《易林补遗》认为伏吟不吉、反吟最凶，不看用神旺衰，一概认为反伏是凶途。但野鹤此论，以比之井卦（占随官上任）为例，世爻逢冲克，虽反吟，身受其殃；以临之中孚卦（占升迁）为例，世官得地，虽反吟，官连迁转。这种教人之法，何等透彻明快！关键还是看用神旺衰，不能一概而论。

## 三、旬空章

### 3.1 旬空基本定义

**原文**：
甲子旬中，戌亥空。甲戌旬中，申酉空。甲申旬中，午未空。
甲午旬中，辰巳空。甲辰旬中，寅卯空。甲寅旬中，子丑空。

**旬空配对表**：

| 旬首 | 空亡地支 | 说明 |
|------|----------|------|
| 甲子旬 | 戌、亥 | 甲子至癸酉10日，戌亥空 |
| 甲戌旬 | 申、酉 | 甲戌至癸未10日，申酉空 |
| 甲申旬 | 午、未 | 甲申至癸巳10日，午未空 |
| 甲午旬 | 辰、巳 | 甲午至癸卯10日，辰巳空 |
| 甲辰旬 | 寅、卯 | 甲辰至癸丑10日，寅卯空 |
| 甲寅旬 | 子、丑 | 甲寅至癸亥10日，子丑空 |

**现代白话解释**：
旬空，又称空亡，是指在六十甲子中，每十天为一旬，每旬中有两个地支不在这十天之内，这两个地支就是空亡。

**原文**：
何谓旬空？如甲子至癸酉日为一旬，此十日之内，并无戌亥，所以爻逢戌亥为空亡，又名旬空。余仿此。

判断方法：看占卜当日的日辰属于哪一旬，该旬没有出现的两个地支就是空亡。卦中爻的地支如果是空亡地支，该爻即为旬空。

### 3.2 旬空判断方法

**原文**：
旬空之法，诸书之论太繁，有真空、假空、动空、冲空、填空、援空、无故自空、有故而空、墓空、绝空、害空、安空、破空。

**野鹤曰**：
旺不为空，动不为空，动而化空，伏而旺相，皆不为空，有日建动爻生扶者，亦不为空，月破为空，有气不动亦为空，伏而被克亦为空，真空为空。（真空者：春土、夏金、秋是木，三冬逢火是真空。）

**现代白话解释**：

**不为空的情况**：
1. **旺不为空**：爻临月建或日辰旺相，虽空不为真空
2. **动不为空**：动爻虽空不为空
3. **动而化空**：动爻化出空亡也不为空
4. **伏而旺相**：伏神旺相不为空
5. **有日建动爻生扶者**：有日辰或动爻生扶也不为空

**为空的情况**：
1. **月破为空**：被月建冲破为空
2. **有气不动亦为空**：有气但不动也为空（存疑）
3. **伏而被克亦为空**：伏神被飞神克制为空
4. **真空为空**：真空必空

**真空定义**：
- **春土**：土在春天休囚为真空
- **夏金**：金在夏天休囚为真空
- **秋木**：木在秋天休囚为真空
- **冬火**：火在冬天休囚为真空

### 3.3 旬空吉凶总论

**原文**：
余初学卜，凡遇旬空，茫然莫辨，欲断为到底全空，却又应乎填实之日而不空，以之为不空，却又到底全空。后得多占之法，凡遇旬空，命之再占，卦吉者，许之出旬而不空；卦凶者，许之空矣。

**作者实战经验**：
初学时遇旬空难以判断，有时断为空却填实，有时断不空却真空。后来总结出方法：**凡遇旬空，命之再占。卦吉者，许之出旬填实不空；卦凶者，许之空矣。**

4. **后卦吉象**：父母午火动虽逢空，但得日月生扶，且父动克世（速至之象）
5. **综合判断**：前卦未父持世，出空见父；后卦父生克世，必然到来
6. **应期准确**：许其未日必到，果然未日返舍
7. **神机辨析**：要识来人之念，父亲熟道往来非远涉江湖，问的是何日回非吉凶安危，故前卦真空是指"未日即至"非"不归"

**次日辨析**：
次日，友问不以月伤日合而断大雨，何其神乎？

余曰：非独昨日之卦也，丑日占过，原应巳日必雨，犹我问神，前卦应今日雨，今果雨否？犹神答今日申时有雨，乌在乎克与合也。

前卦断行人，亦犹彼问我父何日回？亦犹神答未日必至，不在乎空而真也。凡卜者，必与鬼神合其机，切勿刻舟以求剑，余得多占之法，虽未能合鬼神之机，亦能参悟鬼神之机矣。

**现代白话解释**：
1. **前卦应期**：己丑日占得临之师，父母巳火动，应巳日必雨
2. **巳日再占**：巳日早晨满天红日，友人再占得既济之革
3. **友人分析**：申金父母虽动，但日月克之，巳申又合，断不雨
4. **野鹤应期**：断申时有雨（父母申金到位）
5. **应验准确**：果然申酉时雷雨交作
6. **神机辨析**：前卦应巳日雨，我再问今日雨否，神答申时有雨。不在乎日月克合，关键是父母申金到位应期
7. **刻舟求剑**：不可执着于克合等表面现象，要参悟神机

**【按】** 此例与例三合看，说明多占之法的精髓：前后卦互相印证，参悟神机所指。前卦应巳日，后卦细化到申时；前卦真空非不归，后卦日合非不雨。关键在于识来人之念，悟鬼神之机。

### 3.5 旬空理论总结

**李我平曰**：
空亡之说，鬼神不测之妙也。似有又无，似无又有，实有到底全空，亦有填实不空，此以多占两卦，合而决之，可谓泄尽造化之微矣。

夫天地之理，皆从空而生，故谓之"悬空以待"。凡占遇空，不可即以为空，须视其所占之事，或近或远。如在旬内，固为空矣，然又有冲空之日、实空之时；如远在一旬之外，许应于出空之日；若占远大之事，尚无定期，非出旬可以成者，须看大象。大象不吉，始可谓到底之空；大象若吉，太岁、月建亦可填之，然总不如多占两卦为妙法也。

**现代白话解释**：

**空亡之妙**：
- 似有又无，似无又有
- 有到底全空，有填实不空
- 多占两卦合决，泄尽造化之微

**判断原则**：
1. **不可即以为空**：遇空不能立即断为空，要综合分析
2. **视所占事近远**：近事看旬内，远事看出空
3. **旬内之空**：固为空，但有冲空之日、实空之时
4. **旬外之事**：许应于出空之日
5. **远大之事**：尚无定期，非出旬可成，须看大象
   - 大象不吉：始为到底之空
   - 大象若吉：太岁月建亦可填之
6. **最妙之法**：多占两卦为妙法

**空不为空的核心**：
- **天地之理，皆从空而生**，故谓之"悬空以待"
- 空是等待的状态，不是绝对的无
- 关键看大象吉凶、远近缓急、来人之念
- 多占之法能参悟神机

**【乾按】** 本章要旨只在空不为空处，详读篇末之论，则得其要领也。
