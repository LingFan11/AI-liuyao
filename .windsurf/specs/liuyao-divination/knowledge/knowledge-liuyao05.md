## 一、六冲章

### 1.1 六冲基本定义

**原文**：
子午相冲，丑未相冲，寅申相冲，卯酉相冲，辰戌相冲，巳亥相冲。

**六冲配对表**：

| 地支 | 冲的对象 | 方位关系 | 五行关系 |
|------|----------|----------|----------|
| 子（鼠）水 | 午（马）火 | 南北对冲 | 水火相冲 |
| 丑（牛）土 | 未（羊）土 | 东北-西南 | 土土相冲 |
| 寅（虎）木 | 申（猴）金 | 东北-西南 | 金木相冲 |
| 卯（兔）木 | 酉（鸡）金 | 东西对冲 | 金木相冲 |
| 辰（龙）土 | 戌（狗）土 | 东南-西北 | 土土相冲 |
| 巳（蛇）火 | 亥（猪）水 | 东南-西北 | 水火相冲 |

**现代白话解释**：
六冲是指十二地支中相互对立、冲突的关系。就像针锋相对的敌人，相冲代表冲击、破坏、分离的力量。在六爻卦中，如果用神遇到六冲，往往意味着阻碍、破败、散失。但冲也不全是坏事，有时可以"冲散凶神"，或"冲开合局"，释放被束缚的力量。

### 1.2 六冲的六种作用

**原文**：
相冲之法有六：
- 日月冲爻者，一也。
- 卦逢六冲者，二也。
- 六合卦变六冲者，三也。
- 六冲卦变六冲者，四也。
- 动爻变冲者，五也。
- 爻与爻冲者，六也。

**详细解释**：

#### 1. 日月冲爻
**解析**：日辰或月建冲卦中某爻。

**现代白话解释**：
日月的冲击力最强，就像强风吹倒大树。如果用神被日月所冲，往往凶多吉少，主散失、破败。但如果忌神被日月所冲，反而是好事，敌人被打倒了。特别注意：月冲的力量大于日冲。

#### 2. 卦逢六冲
**解析**：本卦就是六冲卦（如乾为天、坎为水等八纯卦）。

**现代白话解释**：
六冲卦主分离、散失、不稳定。占婚姻得六冲卦，往往主分离；占求财得六冲卦，主财散；但占官讼得六冲卦，反而主散解，官司可解；占疾病得六冲卦，病情容易变化。

#### 3. 六合变六冲
**解析**：六合卦变成六冲卦。

**现代白话解释**：
和谐的局面突然转向分离冲突。这种变化往往意味着由好转坏，先吉后凶。占事得此，主先合后散，事情难以长久。

#### 4. 六冲变六冲
**解析**：六冲卦变成另一个六冲卦。

**现代白话解释**：
冲上加冲，散上加散。这种卦象主事情彻底破裂，无法挽回。但占凶事、官讼等，反而主速散速解。

#### 5. 动爻变冲
**解析**：动爻变出的爻与本爻相冲（如午火动化子水，子午相冲）。

**现代白话解释**：
动爻变出来的爻反过来冲克本爻，叫"动化回头冲"，如同自己打自己，或者遇到仇敌反击。这种情况往往主事情反复、自相矛盾、进退两难。

#### 6. 爻与爻冲
**解析**：动爻去冲静爻，或静爻被动爻冲。

**现代白话解释**：
动爻冲静爻，就像主动出击打破平衡。如果用神被冲，主散失、破败；如果是冲开合局，反而能解放被束缚的力量；如果冲散忌神，则是好事。

### 1.3 六冲吉凶总论

**原文**：
冲者，散也。凡占凶事，宜于冲散；占吉事，则不宜。亦必兼用神而言，用神若旺，虽冲不碍；用神失陷，凶而又凶。至六合卦变六冲者，用神纵旺，亦始吉终凶，图事虽成，有头而无尾也。

**爻冲有五**：
1. **月冲** - 爻遇月冲，为月破
2. **日冲旺爻** - 静爻旺相遇日冲，为暗动
3. **日冲衰爻** - 休囚而遇日冲，谓日破
4. **动化回头冲** - 动爻自化回头冲，如逢仇敌
5. **爻冲爻** - 爻遇爻冲，谓之相击

**吉凶判断要点**：

1. **用神旺虽冲不碍** - 用神旺相，虽遇冲不妨碍
2. **用神衰遇冲大凶** - 用神失陷休囚，遇冲则凶而又凶
3. **六合变六冲** - 始吉终凶，图事虽成，有头而无尾
4. **六冲变六冲** - 冲上加冲，彻底破裂，难以挽回
5. **占凶事宜冲** - 占官讼、疾病、忧患遇六冲，主速散速解

**现代白话解释**：
六冲的吉凶判断，关键看冲的是谁：
- 如果冲的是用神（代表你要问的事），那就是破坏你的目标，大凶
- 如果冲的是忌神（对你不利的因素），那是帮你消除障碍，大吉
- 如果冲开了合局，要看这个合局本来是好是坏
- 占婚姻、求财、功名遇六冲，往往主散失不成
- 占官讼、疾病、忧患遇六冲，反而主速散速解，是好事

### 1.4 六冲实战卦例

#### 例一：占子与人相打（六冲变六合有人劝解）

**如：亥月壬子日（旬空：寅卯），占子与人相打，可遇害否？得"大壮之泰"卦**

**本卦：坤宫雷天大壮（六冲）**
```
白虎              兄弟庚戌土  ━ ━
螣蛇              子孙庚申金  ━ ━
勾陈              父母庚午火  ━━━ 世  ○→
朱雀              兄弟甲辰土  ━━━
青龙              官鬼甲寅木  ━━━
玄武              妻财甲子水  ━━━ 应
```

**变卦：坤宫地天泰（六合）**
```
子孙癸酉金  ━ ━ 应
妻财癸亥水  ━ ━
兄弟癸丑土  ━ ━
兄弟甲辰土  ━━━ 世
官鬼甲寅木  ━━━
妻财甲子水  ━━━
```

**解析**：
- 占儿子打架：以子孙爻为用神（代表儿子），但此卦以世爻看父亲
- 卦象：六冲卦变六合卦
- 动爻：世爻午火父母动化丑土
- 月建：亥月
- 日建：子日冲世爻午火

**断曰**：六冲变六合，必有人劝解。父爻持世而克子，乃父责子也，不受他人之害。顷之，有人相请论理，其子理亏，父执棍欲击，被劝而止。

**实际应验**：夫厮打不成者，乃六冲之变合也。父击子而被劝者，乃因日辰子水冲克世爻，故不能以击子也。

**现代白话解释（包括解析、断曰和实际应验）**：
1. **六冲变合有劝解**：六冲卦变六合卦，主原本分离冲突的局面会有人调和劝解，最终不会成事。
2. **父爻持世责子**：世爻午火为父母爻，克应爻子水（子孙）。这不是他人伤害儿子，而是父亲责备儿子。
3. **日辰冲世不能打**：子日冲克世爻午火父母，使父亲力量受损，虽然想打儿子，却被日辰所制，打不成。
4. **动而逢冲非散**：古书说"动而逢冲曰散"，但此卦午火世动，冬令休囚，动遇子日冲，并非如无，身已动、已击子，只是被劝而止。此验证"神兆机于动，动则必验"之理。

#### 例二：占财（冲空则实）

**又如：巳月戊戌日（旬空：辰巳），占财，得"风雷益"卦**

**本卦：巽宫风雷益**
```
朱雀              兄弟辛卯木  ━━━ 应
青龙              子孙辛巳火  ━━━
玄武              妻财辛未土  ━ ━
白虎              妻财庚辰土  ━ ━ 世
螣蛇              兄弟庚寅木  ━ ━
勾陈              父母庚子水  ━━━
```

**解析**：
- 用神：妻财辰土持世（代表钱财）
- 旬空：辰土值旬空
- 日建：戌日冲辰土
- 月建：巳月生辰土

**断曰**：辰土财爻持世，因值旬空，戌日冲空则实，本日即得。

**实际应验**：已如其卜。

**现代白话解释（包括解析、断曰和实际应验）**：
1. **财爻持世**：占求财得妻财辰土持世，用神临世本吉。
2. **旬空被冲**：但辰土值旬空（辰巳旬空），空则无力。
3. **冲空则实**：关键在于戌日冲辰土，"冲空则实"，旬空之爻遇日冲反而填实有用。
4. **当日得财**：戌日冲实辰土财爻，本日即得财。应验"冲空则实"之理。

#### 例三：占出外经商（反吟卦冲中逢合）

**又如：午月丙辰日（旬空：子丑），占出外经商贸易，财喜何如？得"恒之豫"卦**

**本卦：震宫雷风恒**
```
青龙              妻财庚戌土  ━ ━ 应
玄武              官鬼庚申金  ━ ━
白虎              子孙庚午火  ━━━
螣蛇              官鬼辛酉金  ━━━ 世   ○→
勾陈  兄弟庚寅木   父母辛亥水  ━━━      ○→
朱雀              妻财辛丑土  ━ ━
```

**变卦：震宫雷地豫（六合）**
```
妻财庚戌土  ━ ━
官鬼庚申金  ━ ━
子孙庚午火  ━━━ 应
兄弟乙卯木  ━ ━
子孙乙巳火  ━ ━
妻财乙未土  ━ ━ 世
```

**解析**：
- 用神：妻财戌土、丑土、未土（代表财运）
- 动爻：世爻酉金动化卯木（酉卯相冲），亥水动化巳火（亥巳相冲）
- 伏神：兄弟寅木伏于亥水之下
- 卦象：反吟卦
- 月建：午月
- 日建：辰日合酉金（辰酉合）

**断曰**：世爻酉金，化卯相冲，乃反吟之卦。幸辰日合之，冲中逢合，又得戌土为财，暗动生世，虽则反复不常，却有财利。

**实际应验**：果然此人去而复反者三次，尽在中途发货。前曰："爻动化冲，如逢仇敌。"乃是化回头之克也。此卦世爻酉金，化卯冲世而不克世，又得辰日冲动戌财生世，所以为吉。

**现代白话解释（包括解析、断曰和实际应验）**：
1. **反吟之卦**：世爻酉金动化卯木，酉卯相冲；亥水动化巳火，亥巳相冲。动化回头冲，名为反吟卦，主反复不定。
2. **冲中逢合**：虽然酉金化卯相冲，但辰日与酉金相合（辰酉合），冲中有合，缓解冲克之势。
3. **财爻暗动生世**：戌土财爻被辰日冲而暗动，财爻生世爻酉金，虽反复却有财利。
4. **动化冲不克**：前文说"爻动化冲如逢仇敌"，是指动化回头克。但此卦酉金化卯木，卯木不克酉金（金克木），所以虽冲不克，反而无妨。
5. **应验反复**：果然此人去而复返三次，都在中途发货。虽反复不定，但终有财利。应验"冲中逢合"，又得财生世之象。

#### 例四：占文书（爻冲爻旺金冲木不散）

**又如：酉月庚子日（旬空：辰巳），占文书，得"讼之睽"卦**

**本卦：离宫天水讼（游魂）**
```
螣蛇              子孙壬戌土  ━━━
勾陈              妻财壬申金  ━━━     ○→
朱雀              兄弟壬午火  ━━━ 世
青龙  官鬼己亥水   兄弟戊午火  ━ ━
玄武              子孙戊辰土  ━━━
白虎              父母戊寅木  ━ ━ 应  ×→
```

**变卦：艮宫火泽睽**
```
兄弟己巳火  ━━━
子孙己未土  ━ ━
妻财己酉金  ━━━ 世
子孙丁丑土  ━ ━
父母丁卯木  ━━━
兄弟丁巳火  ━━━ 应
```

**解析**：
- 用神：父母寅木（代表文书），应爻发动
- 伏神：官鬼亥水伏于兄弟午火之下
- 动爻：申金动化未土、寅木动化巳火
- 月建：酉月（金旺）
- 日建：子日生寅木

**断曰**：寅木父母爻为文书，动而生世，文书必妥。但嫌申金财动，冲克文书，须待寅日冲去申金，文书必发。

**实际应验**：果寅日得领。古以爻冲爻，亦谓之散，旺相之爻，能冲散衰弱之爻，此卦申值秋时，不为不旺，旺金冲寅而寅木何尝散耶。

**现代白话解释（包括解析、断曰和实际应验）**：
1. **父母动生世**：父母寅木应爻发动生世爻午火，文书本应顺利。
2. **申金冲寅木**：但申金妻财发动，申寅相冲，金克木，财爻冲克文书，有阻碍。
3. **待寅日冲申**：须待寅日，寅日冲去申金，文书才能到手。
4. **旺金冲木不散**：古书说"爻冲爻谓之散"，认为旺相之爻能冲散衰弱之爻。但此卦申金虽值秋月（酉月）旺相，冲寅木而寅木并未散去。因寅木得子日生，又动而生世，有力不散。寅日反冲去申金，文书如期而至。证明"动而逢冲不一定散"，要看爻的旺衰和动静。

#### 例五：占以财搏艺（六冲日冲财反生应）

**又如：子月己巳日（旬空：戌亥），占以财搏艺，得"坤卦"**

**本卦：坤宫坤为地（六冲）**
```
勾陈              子孙癸酉金  ━ ━ 世
朱雀              妻财癸亥水  ━ ━
青龙              兄弟癸丑土  ━ ━
玄武              官鬼乙卯木  ━ ━ 应
白虎              父母乙巳火  ━ ━
螣蛇              兄弟乙未土  ━ ━
```

**解析**：
- 用神：世爻（代表自己）
- 卦象：坤为地六冲卦
- 日建：巳日冲亥水财爻暗动
- 月建：子月

**断曰**：世克应，乃为我胜。但因巳日冲动亥水之财，反生应爻，艺虽精，不能取胜，幸卦逢六冲，必不终局。

**实际应验**：果因他事而散，所负无几。

**现代白话解释（包括解析、断曰和实际应验）**：
1. **世克应本吉**：世爻酉金克应爻卯木，本主我胜他负。
2. **日冲财生应**：但巳日冲亥水财爻，亥水暗动反生应爻卯木，财反助敌，虽艺精不能取胜。
3. **六冲主散**：幸好卦逢六冲，主事不长久，果然因他事而散局，所输不多。
4. **六冲吉凶看用神**：此例说明六冲卦用神失陷确实不吉，但占负面之事（赌博输钱）遇六冲反而是好事，散得快输得少。

## 二、暗动章

### 2.1 暗动基本定义

**原文**：
静爻休囚，日辰冲之，为日破；静爻旺相，日辰冲之，为暗动。暗动者，有喜有忌。用神休囚，得元神暗动以相生；忌神明动于卦中，得元神暗动以生用神，皆谓之喜。用神休囚无助，若遇忌神暗动，克害用神者，则谓之忌。

**现代白话解释**：
暗动是指静爻被日辰所冲而产生的特殊状态。分两种情况：
1. **日破**：静爻休囚无气，被日辰所冲，为日破，主破败无用
2. **暗动**：静爻旺相有力，被日辰所冲，为暗动，主暗中发动有力

暗动有喜有忌：
- **喜**：用神休囚，得元神（生用神的爻）暗动相生；或忌神明动克用神，得元神暗动生用神，都是好事
- **忌**：用神休囚无助，遇忌神暗动克害用神，则是坏事

### 2.2 暗动吉凶辨析

**原文**：
古以暗动，福来而不知，祸来而不觉。又曰：吉凶之力则半，迟速之应则缓。究竟何尝不知不觉，又何尝缓耶。

**现代白话解释**：
古人说暗动是"福来而不知，祸来而不觉"，又说"吉凶之力减半，应期迟缓"。但实际上，暗动的应验并非不知不觉，应期也未必缓慢，关键还是要看暗动之爻的旺衰和对用神的作用。

## 三、动散章

### 3.1 动散基本定义

**原文**：
古以日辰冲动爻，谓之冲散，又以爻动冲爻，亦能冲散。余屡试之，旺相者，冲之不散；有气者，冲之不散；休囚者，间有冲散，亦千百中之一二耳。其故何也？盖神兆机于动，动必有因，虽则今日受制，后逢值日而不散也。

**现代白话解释**：
古人认为日辰冲动爻，或动爻冲动爻，都会使动爻散失。但作者经过多次验证发现：
1. **旺相之爻**：冲之不散
2. **有气之爻**：冲之不散
3. **休囚之爻**：偶有冲散，但也是千百中之一二

为什么？因为"神兆机于动"，爻既然动了，必然有其原因。虽然今日受冲制约，但将来逢值日时仍会发挥作用，并不会真正散失。

### 3.3 动散理论辨析

**原文**：
李我平曰：《黄金策》以空亡为重，冲散为轻。《易冒》最重冲散，细阅其疾病章中，有卯月丙寅日，占子病，得渐之观。占病遇子孙而变鬼，百无一生，明系申金子孙变鬼，误作寅日冲散。又如进退章中，申月占卦，酉爻发动，遇卯冲之，亦谓之散，往往错误如此。

**现代白话解释**：
李我平说：《黄金策》认为空亡重要，冲散次要。而《易冒》最重视冲散理论。但仔细看《易冒》书中的疾病章，有卯月丙寅日占子病得"渐之观"卦的例子。占病遇子孙变鬼，本应凶（百无一生），却误认为是寅日冲散申金子孙而判吉。又如进退章中，申月占卦，酉爻发动遇卯日冲之，也说是冲散。这些都是错误的判断。

**关键辨析**：
1. **冲散不可一概而论**：动爻逢冲是否散，要看爻的旺衰
2. **动化变鬼不是散**：子孙变鬼是化回头克，不是冲散，主凶
3. **神兆机于动**：爻既动必有应验，不会轻易散失

**【按】** 爻动逢日冲为冲散，爻动冲爻亦为冲散。然散与不散亦有例外，不可一概而论。本章论述极明，宜细读之。
