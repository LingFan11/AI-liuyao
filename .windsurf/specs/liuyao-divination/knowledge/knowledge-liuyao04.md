## 一、六合章

### 1.1 六合基本定义

**原文**：
子与丑合，寅与亥合，卯与戌合，辰与酉合，巳与申合，午与未合。

**六合配对表**：

| 地支 | 合的对象 | 五行属性 |
|------|----------|----------|
| 子（鼠） | 丑（牛） | 水土合 |
| 寅（虎） | 亥（猪） | 木水合 |
| 卯（兔） | 戌（狗） | 木土合 |
| 辰（龙） | 酉（鸡） | 土金合 |
| 巳（蛇） | 申（猴） | 火金合 |
| 午（马） | 未（羊） | 火土合 |

**现代白话解释**：
六合是指十二地支中相互配合的关系。就像人际关系中的好搭档，两个地支相合代表和谐、协助、团结的力量。在六爻卦中，如果用神得到六合之助，往往意味着有贵人相助、事情顺利。

### 1.2 六合的六种作用

**原文**：
相合之法有六：
1. 日月合爻者一也。如丑月占得坎卦，世爻子水与月建作合是也。
2. 爻与爻合者二也。如占得天地否卦，世应两爻俱动，卯与戌合是也。但有一爻不动，亦不为合。
3. 爻动化合者三也。如占得天风姤卦，世爻丑动，化出子水作合是也。
4. 卦逢六合者四也。如占得天地否卦，内外六爻自相和合者是也，不动亦是。
5. 六冲卦变六合者五也。如占得乾为天卦，乃八纯六冲之卦，若外卦三爻俱动，变为乾之泰卦，谓之六冲而变六合是也。
6. 六合卦变六合者六也。如占得火山旅卦变山火贲卦是也。

**六合作用类型**：

#### 1. 日月合卦爻
**解析**：日辰或月建与卦中某爻形成六合关系。

**现代白话解释**：
就像考试时有人给你递答案，日月作为最大的力量，如果与你的用神形成六合，那是最强的帮助。比如用神是子水，正好遇到丑月或丑日，子丑相合，用神得到最强支持。

#### 2. 动爻相合
**解析**：卦中两个动爻之间形成六合关系。

**现代白话解释**：
两个动爻相合，就像两股力量联手合作。如果其中一个是用神，另一个是元神（帮助用神的爻），那么合作的力量会更强。但如果一个是用神，一个是忌神（克制用神的爻），那就要看谁的力量更强了。

#### 3. 静爻合动爻
**解析**：静止的爻被动爻合住。

**现代白话解释**：
动爻去合静爻，就像主动去拉拢对方。如果用神被忌神合住，就像被敌人缠住手脚，无法发挥作用。如果元神被合住，也不能帮助用神了。

#### 4. 变卦六合
**解析**：本卦变成变卦后，两卦形成六合卦。

**现代白话解释**：
比如乾卦（六爻全是阳爻）变成坤卦（六爻全是阴爻），乾坤相合，整体形成和谐局面。这种六合是大局上的和谐。

#### 5. 合处逢冲
**解析**：原本相合的爻，遇到日月冲破。

**现代白话解释**：
就像本来关系很好的两个人，突然因为外部因素闹翻了。比如子丑相合，但遇到未日（未冲丑），合就被冲破了。冲开了合，原本被束缚的力量就能释放出来。

#### 6. 六合变六冲
**解析**：六合卦变成六冲卦。

**现代白话解释**：
和谐的局面突然转向对立冲突。这种变化往往意味着事情会发生逆转。

### 1.3 爻合的四种状态

**原文**：
爻之合者，静而逢合，谓之合起；动而逢合，谓之合绊；爻与爻合，谓之合好；爻动化合，谓之化扶。

**详细解释**：

1. **合起**：爻静，或与日月动爻合者，得合而起，即使爻值休囚，亦有旺相之意。
2. **合绊**：爻动，或与日月动爻合者，谓之动逢合而绊住，反不能动之意。
3. **合好**：爻动与动爻相合，乃得他来合我，与我和好相助之意。
4. **化扶**：爻动，化出之爻回头相合者，谓之化扶，得他扶助之意。

### 1.4 六合吉凶总论

**原文**：
凡得诸合，诸占皆以为吉。占名名成，占利利就，占婚必成，占身发迹，占宅兴旺，占风水聚气藏风，占求谋遂心合意。然必用神有气相宜，用若失陷无济。卜书云：万事若得三六合，诸事必得久远，有始有终。然吉事逢之，事之必就，凶事逢之，事之难结。


**解析**：

- 月建：丑月与子水相合（子丑合）
- 日建：申日生世爻子水
- 动爻：申金父母发动生世
- 卦象：六冲变六合

**断曰**：世爻子水，丑月合之，申日作父母而生世，卦中之申金又动，兼是六冲变六合，卦称全美，上誉无疑。

**实际应验**：果考一等，即于子科高发。后探之，前试考过四等，以六冲变合，先否后泰之象也。

**现代白话解释（包括解析、断曰和实际应验）**：
1. **用神得力**：世爻子水为用神，丑月与之相合（子丑合），得月建合起之力。
2. **日建生扶**：申日作父母而生世爻子水，日建帮助用神。
3. **动爻助力**：卦中申金父母又发动，父母动而生世，文章有力。
4. **六冲变合**：本卦坎为水是六冲卦，变成泽水困为六合卦，先否后泰之象，卦称全美。果然考得一等，并在子科高中。前试仅考四等，正应六冲变合、先难后易之象。

**断曰**：此卦虽爻逢六合，但不宜戌月冲世、卯日克世，而应爻暗动，月建生之，彼之得志，官事必输。

**实际应验**：已而被杖。被杖者，卯木克世之故耳。用神受克，六合有何益哉？所以凡得诸合，若世爻失陷者，难以吉断。

4. **六合无用**：虽然卦逢六合，但世爻失陷受克，官事必输。果然被打板子，正是卯木克世之应。此例说明：用神受克，六合也无济于事。

### 1.7 合中带克理论

**原文**：
古法子与丑合，丑中有土，土克子水，谓之合中带克，克三合七。巳与申合，巳火克申金，谓之克七合三。

右非通论，余得验者，子丑作合，若于辰戌丑未月日占之，而子水并无他处生扶者，即言克不言合，若有生扶，仍以合论。所以子水逢丑月、戌土遇卯月、申金逢巳月，再遇动爻克者，克而又克，何能言合耶？其克三合七、克七合三之说，有问凶吉者，以此答之，何以决人之疑？

```
朱雀              父母丙戌土  ━ ━
青龙              妻财乙卯木  ━ ━
玄武              官鬼乙巳火  ━ ━ 应
白虎              父母乙未土  ━ ━
```

**解析**：
- 用神：子孙子水（代表儿子）
- 月建：丑月与子水相合（子丑合）
- 日建：辰日克子水
- 动爻：戌土暗动克子水

**断曰**：子水子孙，与月建作合，卦无生扶，言克不言合也。又加日辰克制，辰日又冲动戌土，以克子水，只恐难过辰时。

**实际应验**：果如期而卒。此乃合中遇克，病之不救，岂可谓之克三合七耶？

**现代白话解释（包括解析、断曰和实际应验）**：
1. **合中带克**：子水子孙与月建丑合，但丑中有土克水，卦中又无其他生扶，因此只能言克不言合。
2. **克而又克**：日辰辰土克子水，辰日又冲动戌土，戌土再克子水，多重克制。
3. **病不可救**：用神受多重克制，只恐难过辰时。果然应验，孩子在辰时去世。这种情况绝不能用"克三合七"的说法来判断吉凶。

## 二、六冲章

### 2.1 六冲基本定义

**原文**：
子午冲，丑未冲，寅申冲，卯酉冲，辰戌冲，巳亥冲。

**六冲配对表**：

| 地支 | 冲的对象 | 方位关系 |
|------|----------|----------|
| 子（北） | 午（南） | 南北对冲 |
| 丑（北东） | 未（南西） | 对角冲 |
| 寅（东北） | 申（西南） | 对角冲 |
| 卯（东） | 酉（西） | 东西对冲 |
| 辰（东南） | 戌（西北） | 对角冲 |
| 巳（南东） | 亥（北西） | 对角冲 |

**现代白话解释**：
六冲是指十二地支中相互对立、冲突的关系。就像针锋相对的对手，相冲代表冲击、破坏、分离的力量。在六爻卦中，如果用神遇到六冲，往往意味着阻碍、破败、散失。但冲也不全是坏事，有时可以"冲开合"，释放被束缚的力量。

### 2.2 六冲的作用

**六冲作用类型**：

#### 1. 日月冲卦爻
**解析**：日辰或月建冲卦中某爻。

**现代白话解释**：
日月的冲击力最强，就像强风吹倒大树。如果用神被日月所冲，往往凶多吉少。但如果忌神被日月所冲，反而是好事，敌人被打倒了。

#### 2. 动爻相冲
**解析**：卦中两个动爻之间相冲。

**现代白话解释**：
两个动爻相冲，就像两股力量对抗。如果用神与忌神相冲，要看谁更旺，旺者胜。

#### 3. 动爻冲静爻
**解析**：动爻去冲静止的爻。

**现代白话解释**：
动爻冲静爻，就像主动出击。如果用神被冲，主散失、破败；如果是冲开合局，反而能解放被束缚的力量。

#### 4. 六冲卦
**解析**：本卦就是六冲卦（如乾为天变巽为风）。

**现代白话解释**：
六冲卦主分离、散失、不稳定。占婚姻得六冲卦，往往主分离；占求财得六冲卦，主财散；但占官讼得六冲卦，反而主散解，官司可解。

#### 5. 冲处逢合
**解析**：相冲的爻遇到合的力量。

**现代白话解释**：
本来要冲散的力量，被合住了，冲不动。就像要打架的两个人，被第三者拉开了。

#### 6. 六合变六冲
**解析**：六合卦变成六冲卦。

**现代白话解释**：
和谐的局面突然转向分离冲突。这种变化往往意味着由好转坏，先吉后凶。

## 三、三合章

### 3.1 三合基本定义

**原文**：
申子辰合成水局，巳酉丑合成金局，寅午戌合成火局，亥卯未合成木局。

**三合配对表**：

| 三合局 | 组成地支 | 合成五行 | 长生-帝旺-墓库 |
|--------|----------|----------|----------------|
| 申子辰 | 申、子、辰 | 水局 | 申长生、子帝旺、辰墓库 |
| 巳酉丑 | 巳、酉、丑 | 金局 | 巳长生、酉帝旺、丑墓库 |
| 寅午戌 | 寅、午、戌 | 火局 | 寅长生、午帝旺、戌墓库 |
| 亥卯未 | 亥、卯、未 | 木局 | 亥长生、卯帝旺、未墓库 |

**现代白话解释**：
三合是指三个地支组合成一个五行局。这是比六合更强大的合力，三个地支聚在一起，形成一股强大的五行力量。比如申子辰三个地支合在一起，就形成了强大的水局。三合的力量大于六合，是卦中非常重要的组合形式。

### 3.2 三合的四种作用

**原文**：
此三合者有四：
一卦之内，有三爻动而合局者，一也。
两爻动，一爻不动，亦成合局者，二也。
有内卦初爻、三爻动，动而变出之爻成三合者，三也。
有外卦四爻、六爻动，动而变出之爻成三合者，四也。

余按：此三合局者，有凶有吉。

**详细解释**：

#### 1. 三爻俱动成局
**解析**：卦中三个爻都发动，正好形成三合局。

**现代白话解释**：
比如申爻动、子爻动、辰爻动，三个都动起来，形成申子辰水局。这是最强的三合，三股力量齐发，威力巨大。

#### 2. 两动一静成局
**解析**：两个爻发动，一个爻不动，也能形成三合局。

**现代白话解释**：
比如申爻动、子爻动，辰爻虽然不动，但也参与合局。只要有两个爻动，第三个爻即使静止，也能被带动起来形成三合局。

#### 3. 内卦变出成局
**解析**：内卦初爻、三爻动，变出的爻成三合局。

**现代白话解释**：
内卦的初爻和三爻发动，变化后的爻正好形成三合局。这种三合局影响内部事务。

#### 4. 外卦变出成局
**解析**：外卦四爻、六爻动，变出的爻成三合局。

**现代白话解释**：
外卦的四爻和六爻发动，变化后的爻正好形成三合局。这种三合局影响外部事务。

### 3.3 三合吉凶理论

**原文**：
如占功名，合成官局，谓之官旺；倘合成财局，谓之财旺生官；倘合成子孙局者，乃伤官之神也。占求财，如合成财局，谓之财库；合成子孙局者，谓之子孙局生财；倘合成兄弟之局，乃破败、耗财、阻隔之神也。占祖茔、家宅，宜父母爻而合局；占婚姻、夫妇，宜财官旺而合局。占久远喜庆之事，宜于成局，永远坚牢；若占官讼、忧疑事而合局者，终身锢结其心，难于消释。

但三合其局者，用神旺，则无不为吉，尤要世爻在局为美。若世爻不在局内，亦须局生世爻，始以吉断。倘局克世爻，则以凶推。至于日建月建，但有一在局中，谓之局旺，更吉。三爻若只两爻动，不为成局。须待后来之月日补凑，合成其局，谓之虚一待用。一爻明动，一爻暗动，亦作两爻动。三合局中，有一值空破者，待填实之日月成之。有一爻入墓者，待冲开之日成之。

更有当知者：如占功名，三合官局而生世者，利于我；生应者，利于他。占财，财局生世，利于我；财局生应，利于他。占出行，用神在三合之内，被合而留。占行人，用神在三合之内，被合不返。

又有内卦外卦而成三合者，须分内外。如占家宅，若居内宅，不宜外卦克内，若居外宅，须宜内卦生外。如占彼此之形者，内卦为我，外卦为他，外卦合局而生内卦者为吉，克内卦者为凶。

**现代白话解释**：
判断三合吉凶的核心要点：
1. **占功名**：合成官局为官旺大吉，合成财局为财生官吉，合成子孙局则伤官不利。
2. **占求财**：合成财局为财库大吉，合成子孙局为生财吉，合成兄弟局则破财凶。
3. **占家宅风水**：宜父母爻合局。占婚姻：宜财官旺合局。
4. **用神旺则吉**：三合成局，用神旺则无不为吉，最美是世爻在局中。
5. **局生世吉**：世爻不在局中，局生世爻也吉；局克世爻则凶。
6. **日月在局**：日建或月建有一在局中，谓之局旺，更吉。
7. **虚一待用**：只有两爻动不成局，须待后来月日补凑，谓之虚一待用。
8. **明暗皆动**：一爻明动、一爻暗动，也作两爻动。
9. **空破入墓**：局中有一爻值空破，待填实日月成之；有一爻入墓，待冲开日成之。
10. **内外分别**：内卦为我，外卦为他。外卦合局生内卦为吉，克内卦为凶。

### 3.5 三合实战卦例


**变卦：坤宫坤为地（六冲）**
```
妻财癸酉金  ━ ━ 世
官鬼癸亥水  ━ ━
子孙癸丑土  ━ ━
父母乙卯木  ━ ━ 应
兄弟乙巳火  ━ ━
子孙乙未土  ━ ━
```

**解析**：
- 内卦：亥水官鬼、卯木父母、未土子孙，形成亥卯未木局（代表我村）
- 外卦：巳火兄弟、酉金妻财、丑土子孙，形成巳酉丑金局（代表他村）
- 关系：金克木，彼强我弱之象
- 卦象：六冲卦变六冲卦

**断曰**：内卦为我村，亥卯未合成木局；外卦为他村，巳酉丑合成金局。金来克木，彼赢我负之象，幸衰金不克旺木，不足畏也。况系六冲卦变六冲，有人解散，必不成非，后果劝散。

**实际应验**：或问：彼此之势，必以世应为主，此如何不言世应？余曰：若无内外合局者，须看世应，今彼此两村，即内外两卦，人众同心，彼此合局，神之妙用，妙验显然，故舍世应而不用也。若非卦化六冲，未有不成非也。

**现代白话解释（包括解析、断曰和实际应验）**：
1. **内外三合**：内卦亥卯未合成木局代表我村，外卦巳酉丑合成金局代表他村。这是典型的内外卦三合对峙。
2. **金克木象**：金局克木局，表面看彼强我弱。但因金为衰金、木为旺木（卯月），衰金克不动旺木，不足为惧。
3. **六冲解散**：关键在于六冲变六冲，主事情会散开，有人调解。果然后来被劝散，没有成讼。
4. **舍世应用内外**：此卦不看世应，而看内外三合，因为是两村集体对抗，神之妙用在于内外合局。

3. **寅日应验**：少寅字，必待寅日才能成局。果然在寅日递呈，被特别简拔题用，完全应验"虚一待用"之理。

- 月建：寅月，借月建成三合
- 关键：午火明动，戌土暗动（被辰日冲），明暗皆动

**断曰**：此卦若以吉法断，午火官星一爻独发，当许午月。如以动而逢合，必待冲开，当许子丑之月。今余不以此断。午火明动，戌爻暗动，三合而少寅字，借月建以成三合，本月必选。

**实际应验**：果于本月选于闽中。夫应选闽地者，因世爻动于六爻，又是官临午火之故耳。此乃明动暗动，合成局也。

**现代白话解释（包括解析、断曰和实际应验）**：
1. **明暗皆动**：午火官鬼明动，戌土父母被辰日冲而暗动。一爻明动、一爻暗动，也作两爻动，可以成局。
2. **借月建成局**：寅木妻财不动，但正好是寅月，借月建以成寅午戌三合火局。三合官局，本月必选。
3. **闽中应验**：果然在本月（寅月）被选派到福建。选在闽地，因世爻在六爻，官鬼又临午火（南方）之故。此例说明明动暗动合成局的妙用。

#### 例四：占辨复（财局生官）

**又如：辰月丁亥日（旬空：午未），占辨复，得"萃之革"卦**

**本卦：兑宫泽地萃**
```
青龙              父母丁未土  ━ ━
玄武              兄弟丁酉金  ━━━ 应
白虎              子孙丁亥水  ━━━
螣蛇              妻财乙卯木  ━ ━        ×→
勾陈              官鬼乙巳火  ━ ━ 世
朱雀              父母乙未土  ━ ━        ×→
```

**变卦：坎宫泽火革**
```
父母丁未土  ━ ━
兄弟丁酉金  ━━━
子孙丁亥水  ━━━ 世
子孙己亥水  ━━━
父母己丑土  ━ ━
妻财己卯木  ━━━ 应
```

**解析**：
- 用神：官鬼巳火（代表官职复用）
- 三合：亥水子孙+卯木妻财动+未土父母动，形成亥卯未木局
- 作用：木局生火，财局生官
- 世爻：官鬼巳火持世
- 驿马：亥日冲巳火暗动

**断曰**：内卦，亥卯未合成财局，生世爻巳火之官。世爻巳火，驿马加临，亥日冲之而暗动，须莫惜费，未月定蒙题允，还得美缺。

**实际应验**：后于未月果得题复，补楚中。应未月者，乃实空之月也。

**现代白话解释（包括解析、断曰和实际应验）**：
1. **财局生官**：内卦亥卯未三合成木局，木为财局，财局生世爻巳火官鬼。占辨复得财局生官，大吉之象。
2. **驿马暗动**：世爻巳火临驿马，亥日冲巳而暗动，主有远行赴任之象。须不惜费用（财局耗财）。
3. **未月题复**：未土父母发动，又在亥卯未木局中。未月实空（原旬空午未），定能得到批准，还能得到好的职位。果然在未月得题复，补任楚中（湖广）。

**【按】** 卦中六合，三合成局，合中有吉，合中有凶，且与日辰月建，动爻静爻，内卦外卦，主卦变卦，关系甚紧，变化微妙，解此章者，尤应逐项牢记，参考卦例，悟出通变之处，方可言解。

## 四、总结与应用建议

### 4.1 六合六冲三合判断口诀

**六合主事**：
- 合则有情，主和谐、协助、团结
- 用神得合，主有贵人相助
- 忌神被合，主敌人被牵制
- 合处逢冲，主先合后散

**六冲主事**：
- 冲则无情，主分离、破败、散失
- 用神遇冲，主事败人亡
- 忌神被冲，主敌人瓦解
- 冲开合局，主解放束缚

**三合主事**：
- 三合成局，力量最强，三股力量联手
- 局生用神，三人相助，大吉大利
- 局克用神，三敌齐攻，大凶大败
- 世在局中，力量倍增，事半功倍
- 虚一待用，须待月日补凑成局
- 明暗皆动，一明一暗也可成局
- 内外分判，内为我，外为他

### 4.2 实战应用要点

1. **看用神与合冲局的关系**：用神得合则吉，用神逢冲则凶，用神在三合局中最吉
2. **看月日建的作用**：月日合冲的力量最大，日月在三合局中谓之局旺
3. **看动静关系**：动爻合冲静爻力量大，明暗皆动也可成三合局
4. **看六神配合**：青龙合主喜，白虎冲主凶
5. **看变卦情况**：六合卦变六冲，先吉后凶；六冲卦变六合，先难后易
6. **看三合成局**：三合力量大于六合，但须看局生克用神
7. **看内外分判**：内卦为我，外卦为他，内外三合需分别判断

### 4.3 AI解卦算法建议

**数据库设计**：
- 创建六合配对表（子丑合、寅亥合等）

8. 分析动变关系对合冲局的影响
