## 二、占卦法章 - 古卦法（钱币起卦法）

### 2.1 起卦工具
- **使用**: 三枚钱币（以乾隆通宝铜钱为佳）
- **次数**: 共需投掷六次
- **记录**: 从下往上记录，第一次为初爻（最下），第六次为上爻（最上）

### 2.2 钱币判定规则

#### 基本规则
```
首先将三个铜钱放入手心，两手合扣，问事占卜，脑子只准想所要预测之事。
反覆摇动手中铜钱，然后将铜钱掷于手中，看铜钱的情况：
```

#### 爻象判定标准

| 正面数量 | 反面数量 | 称呼 | 符号表示 | 爻性 | 是否变爻 |
|----------|----------|------|----------|------|----------|
| 2个正面  | 1个反面  | 单   | ━━━ "⚊" | 少阳 | 否（静爻） |
| 1个正面  | 2个反面  | 拆   | - - "⚋" | 少阴 | 否（静爻） |
| 0个正面  | 3个反面  | 重   | - - "○" | 老阴 | 是（变爻） |
| 3个正面  | 0个反面  | 交   | ━━━ "×" | 老阳 | 是（变爻） |

**详细说明**：
- **两个正面一个反面** → 称作 "单" → 画作 "⚊"（阳爻） → 少阳
- **两个反面一个正面** → 称作 "拆" → 画作 "⚋"（阴爻） → 少阴
- **三个反面没有正面** → 称作 "重" → 画作 "○"（老阴） → 是变爻
- **三个正面没有反面** → 称作 "交" → 画作 "×"（老阳） → 是变爻

### 2.3 起卦顺序（重要！）

```
第一次为初爻（最下）→ 画在卦的最下面
第二次为第二爻     → 依次往上
第三次为第三爻     → 依次往上
第四次为第四爻     → 依次往上
第五次为第五爻     → 依次往上  
第六次为上爻（最上）→ 画在卦的最上面
```

**画卦出变卦规则**：
```
如果是少阳、少阴，画出本卦即可。
如果出现老阴、老阳，则需要画出变卦。
```

### 2.4 起卦示例

#### 示例1：六爻全部为静爻
```
第一次摇得一拆 → 画作 "⚋"  （少阴，阴爻）
第二次摇得两拆 → 画作 "⚋"  （少阴，阴爻）
第三次摇得三拆 → 画作 "○"  （老阴，变爻）
第四次摇得三交 → 画作 "×"  （老阳，变爻）
第五次摇得三拆 → 画作 "○"  （老阴，变爻）
第六次摇得两拆 → 画作 "⚋"  （少阴，阴爻）
```

#### 示例2：上三交外卦 vs 下三交内卦
```
上三交为外卦:
  六爻    ⚋
  五爻    ○    → 坎为水卦    ━ ━ ○
  四爻    ×                  ━━━ ×

下三交为内卦:
  三爻    ○    → 离为火卦    ━━━ ○
  二爻    ⚋                  ━ ━
  初爻    X                  ━ ━ ×

即得 "水火既济" 卦  →  本卦为 "水火既济"
```

### 2.5 变卦规则详解

**初学点卦时，见到○、×时，可能一时不明白怎么画出变卦来。须要细心、慢想。**

**变卦规则**：
```
现以上卦为例：
- 把第一个 "×" (老阳) 改为 "⚋"（阴爻），成为离中虚卦，为内卦
- 把第四个 "×" (老阳) 改为 "⚋"（阴爻），成为坎中满卦，为外卦
- 把第三个 "○" (老阴) 改为 "⚊"（阳爻），成为坎中满卦
```

**因为坎卦为水，因为起卦时，由下至上，卦卦名时，是由上往下卦，此卦上卦为坎，为水，下卦为离，为火，所以此卦名为"水火既济"。**

**再掷一卦**：

```
第一次得两拆为 "拆" → 画作 "⚋"  （阴爻）
第二次得三拆为 "重" → 画作 "○"  （老阴，变爻）
第三次得三背为 "单" → 画作 "⚊"  （阳爻）
第四次得三交为 "交" → 画作 "×"  （老阳，变爻）
第五次得三字为 "交" → 画作 "×"  （老阳，变爻）
第六次得三背为 "单" → 画作 "⚊"  （阳爻）
```

**变卦过程**：
```
原卦（本卦）:        变卦:
  ⚊                    ⚊
  ×    上三交外卦      ⚋    上三交外卦 "×" 仿真两点，即是离中虚，离为火。
  ×      ↓            ⚋    
  ━                   ━
  ⚋                   ━
  ○                   ⚊    下三交内卦 "○" 仿真一点，既是坎中满，坎为水。

火在上，水在下，卦名为 "火水未济"。
```
