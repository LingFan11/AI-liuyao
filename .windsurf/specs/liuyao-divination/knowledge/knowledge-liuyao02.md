## 一、洋天甲子章 - 六亲五行配置规则

### 1.1 基本原则

**核心规则**：根据卦宫的五行属性，推算每一爻的六亲关系。

**六亲定义**：
- **父母** - 生我者
- **兄弟** - 比和者（与我同类）
- **子孙** - 我生者
- **妻财** - 我克者
- **官鬼** - 克我者

## 二、六亲歌章 - 六亲含义与作用

### 2.1 六亲生克关系核心规则

**生我者为父母，我生者为子孙，我克者为妻财，克我者为官鬼，比和者为兄弟。**

**五行生克速查**：
- 乾兑金克兄弟父，木鬼火鬼水子孙 - **乾兑两宫，八卦俱属金**
- 坎宫木子克属水，金父火财土为鬼 - **坎宫属水**
- 坤艮土克兄子父，水鬼木财金子孙 - **坤艮两宫，八卦俱属土**
- 离宫木父交土子，水鬼金财火克兄 - **离宫属火**
- 震巽木克兄父母，金鬼火子财是土 - **震巽两宫，八卦俱属木**

### 2.2 六亲含义详解（以"乾为天卦"为例）

**卦例：乾为天（乾宫纯卦）**
```
乾宫：乾为天

上爻：父母戌土  ━━━ 世
五爻：兄弟申金  ━━━
四爻：官鬼午火  ━━━
三爻：父母辰土  ━━━ 应
二爻：妻财寅木  ━━━
初爻：子孙子水  ━━━
```

**此卦乾宫卦，即照"乾兑金克兄弟父，木鬼火鬼水子孙"装之。**
- 所以**戌土二土为父母**（土生金）
- **申金为兄弟**（金比金）
- **午火为官鬼**（火克金）
- **寅木为妻财**（金克木）
- **子水为子孙**（金生水）

### 2.3 六亲定义原理（乾卦）

此章即卦中**六亲定法**，学者也可据卦中五行生克之理推定六亲：

**生我者为父母**：
- 我生者为子孙
- 克我者为官鬼
- 我克者为妻财
- 比和者为兄弟

**依此法推求，以不变应万变，妙不可言。**

## 四、动变章 - 变爻与变卦规则

### 4.1 变爻基本规则

**六爻静则不变，动则必变。**

**变化规则**：
- **阳动变阴** - ○为阳动，动则变阴，×为阴动，动则变阳
- **阴动变阳** - 一阴动变一阳，×为阴，动则变一

### 4.2 变卦生成规则

#### 规则1：一爻动变
```
假如乾卦初爻动，则变为姤卦：

本卦（乾为天）：    变卦（天风姤）：
━━━                ━━━
━━━                ━━━
━━━ ○              ━ ━ （老阴变阴爻）
```

#### 规则2：上下爻动
```
假如乾卦上下爻动，则变为坎卦：

本卦：              变卦：
━━━ ○              ━ ━
━━━                ━━━
━━━ ○              ━ ━
```

#### 规则3：三爻动
```
假如乾卦三爻动，则变为乾卦：

本卦：              变卦：
━━━ ×              ━━━
━ ━ ×              ━━━
━ ━ ×              ━━━
```

#### 规则4：中爻动
```
假如乾卦中爻动，则变为坎卦：

本卦：              变卦：
━ ━                ━ ━
━ ━ ×              ━━━
━ ━                ━ ━
```

### 4.3 变卦示例："泽天夬"卦变出"天风姤"卦

假如占得"泽天夬"卦变出"天风姤"卦。

**本卦：坤宫泽天夬**
```
上爻：兄弟丁未土  ━ ━         ×→  
五爻：子孙丁酉金  ━━━ 世            
四爻：妻财丁亥水  ━━━              
三爻：兄弟甲辰土  ━━━              
二爻：官鬼甲寅木  ━━━ 应            
初爻：妻财甲子水  ━━━         ○→  
```

**变卦：乾宫天风姤**
```
上爻：兄弟壬戌土  ━━━
五爻：子孙壬申金  ━━━
四爻：父母壬午火  ━━━ 应
三爻：子孙辛酉金  ━━━
二爻：妻财辛亥水  ━━━
初爻：兄弟辛丑土  ━ ━ 世
```

**去"泽天夬"为正卦，所变"天风姤"为之卦。以姤卦初爻之丑土，写在夬卦初爻发动子水之旁，谓之子水变出丑土；以姤卦第六爻之戌土，写在夬卦六爻发动未土之旁，即是未土变出戌土。**

余爻不动不变，不必写出。

### 4.4 变卦重要原则

**安六亲者，姤卦之丑土戌土原是父母，今俱写兄弟。**

盖六亲须照前卦之生克而安也。前卦泽天夬，土为兄弟。所以变卦之丑戌二土，亦写兄弟。余卦仿此。

**【按】** 爻动卦必变，变卦中六亲须按正卦而推。初学者往往照变卦而写，则大错特错。断卦必难准确，万望慎而又慎。

## 五、用神章 - 用神选取方法

### 5.1 用神选取总则

#### 父母爻

**用神选取**：
- 占父母，即以卦中之父母爻为用神。
- 祖父母、伯叔、姑、姨父母，凡在我父母之上，或与我父母同辈之亲，及师长、妻父母、乳母、拜认之父母、三父、八母，或仆占主人，皆以父母爻为用神。

**物类范围**：
- 占天地、城池、墙垣、宅舍、屋宇、舟车、衣服、雨具、绸缎、布匹、杂货、及章奏、文书、文章、书馆、文契，亦以父母爻为用神。
- 物类亦多，在人通变，一切庇护我身者是也。

#### 官鬼爻

**用神选取**：
- 占功名、官府、雷霆、鬼神、妻占夫，皆以官鬼爻为用神。
- 占乱臣、贼盗、邪祟，亦以官鬼爻为用神。
- 物类亦多，一切拘束我身者是也。

#### 兄弟爻

**用神选取**：
- 占兄弟、姐妹、族中兄弟、姑姨、姐夫、妹夫、及结拜弟兄，皆以兄弟爻为用神。

**负面作用**：
- 兄弟乃同类之人，彼得志则欺陵，见财则夺，所以占财物，以此为劫财之神。
- 占谋事，以此为阻隔之神。
- 占妻妾、婢仆，以此为刑伤克害之神。

**特殊情况**：
- 占姐夫、妹夫，以世爻为用神，予屡得验。
- 占表兄弟，以兄弟爻为用神而不验，还以应爻为用神。

#### 妻财爻

**用神选取**：
- 占妻妾、婢仆、下役，凡我驱使之人，皆以财爻为用神。
- 占货财、珠宝、金银、仓库、钱粮，一切使用之财物、什物、器皿，亦以财爻为用神。

#### 子孙爻

**用神选取**：
- 占子孙、占女儿、女婿、侄儿、外甥、门徒，凡在我子孙辈中，皆以子孙爻为用神。
- 占忠臣、良将、医士、医药、僧、道、兵、卒，皆以子孙爻为用神。
- 占六畜、禽兽，亦以子孙爻为用神。

**功能作用**：
- 子孙为福德之神、为制鬼之神、为解忧之神、又为剥官、退职之神。
- 故谓之子孙乃是福神，诸事见之为喜，独占功名者忌之。

### 5.2 用神选取原则总结

**【按】** 用神者，实为卦中所占事之六亲标志也。用即取用，神指阴阳二气之变化也。取准用神与测占灵验至关紧要，倘用神错取，则百无一用矣。

## 六、解卦核心要点

### 6.1 解卦基本流程

1. **确定卦宫** - 判断属于八宫中的哪一宫（决定五行属性）
2. **安六亲** - 根据卦宫五行，配置六亲
3. **定世应** - 确定世爻和应爻位置
4. **看动变** - 判断哪些爻动，生成变卦
5. **取用神** - 根据占问事项，选取用神
6. **析生克** - 分析用神与其他爻的生克关系

### 6.2 解卦关键要素

**必须掌握的核心要素**：
1. **八宫归属** - 六十四卦的八宫分类
2. **五行生克** - 金木水火土相生相克
3. **六亲关系** - 父母、兄弟、子孙、妻财、官鬼
4. **世应定位** - 世爻代表自己，应爻代表对方
5. **动爻变化** - 老阴老阳变爻规则
6. **用神选取** - 根据占事选择核心爻

## 七、用神、元神、忌神、仇神章

### 7.1 四神定义

**用神者，即前各类之用神。元神者，生用神之爻，即为元神。忌神者，克用神之爻也，即为忌神。仇神者，克制元神不能生用神，反生忌神而克害用神，即为仇神。**

**四者关系**：
- **用神** - 所占事项对应的六亲爻
- **元神** - 生用神之爻（如金为用神，土生金，土为元神）
- **忌神** - 克用神之爻（如金为用神，火克金，火为忌神）
- **仇神** - 克元神、生忌神之爻（如金为用神，土为元神，火为忌神，木克土生火，木为仇神）

**占卦要诀**：
- 不拘占何事，先看何爻为用神。
- 既得用神，须看旺相否？
- 有元神动而生扶否？
- 有忌神动而克害否？

### 7.2 用神实例详解

#### 例一：占往营中贸易

**断曰**：不可往，必有仇人为害。或曰：应爻酉金，克世为忌神，何谓仇人？余曰：世为自己，应为他人。应爻生世，即为恩人；应克世，非仇而何？后果被仇人陷害。勿以仇神即仇人也。

### 7.3 元神、忌神、衰旺章

#### 7.3.1 有力之元神

**元神虽生用神，须要旺相，方能生得用神。元神能生用神者有五：**

1. **元神旺相，或临日月，或得日月动爻生扶者，一也。**
2. **元神动，化回头生，及化进神者，二也。**
3. **元神长生、帝旺于日辰，三也。**
4. **元神与忌神同动，四也。**
5. **元神旺动，临空、化空，五也。**

**此五者，乃有力之元神也，诸占皆吉。**

**【按】** 古以临空、化空为无用，非也。殊不知动不为空，待冲空、实空之日，而为有用。

**如：酉月辛亥日（旬空：寅卯），占谒贵求财，得"兑之解"卦**

**断曰**：甲寅日得见，财亦如心。彼曰："卯木财爻，空而且破，又被金克，初爻巳火官虽生世，亥日冲散，又化旬空，何以为吉？"余曰：神兆机于动，余从来不言散，正因巳火化空，所以目下不见，待甲寅日出空而相见矣。寅木之财以生官，官来生世，故断甲寅日见，财亦如心。后果于寅日得见，本日获财。

#### 7.3.2 无用之元神

**元神虽现，又有不能生用神者有六：**

1. **元神休囚不动，或动而休囚，又被伤克，一也。**
2. **元神休囚，又逢旬空、月破，二也。**
3. **元神休囚，动化退神，三也。**
4. **元神衰而又绝，四也。**
5. **元神入三墓，五也。**
6. **元神休囚，动而化绝、化克、化破、化散，六也。**

**以上元神见生不生，无力生用神，乃无用之元神也，虽有如无。**

#### 7.3.3 有力之忌神

**忌神动而克害用神者有五：**

1. **忌神旺相，或遇日月动爻生扶，或临日月，一也。**
2. **忌神动，化回头生、化进神，二也。**
3. **忌神旺动，临空、化空，三也。**
4. **忌神长生帝旺于日辰，四也。**
5. **忌神与仇神同动，五也。**

**以上乃有力之忌神，势同斧钺，诸占大凶。**

#### 7.3.4 无力之忌神

**忌神虽动，又有不能克用神者有七：**

1. **忌神休囚不动，动而休囚，被日月动爻克，一也。**
2. **忌神静，临空破，二也。**
3. **忌神入三墓，三也。**
4. **忌神衰，动化退神，四也。**
5. **忌神衰而又绝，五也。**
6. **忌神动，化绝、化克、化破、化散，六也。**
7. **忌神与元神同动，七也。**

**以上乃无力之忌神也，诸占化凶为吉。**

**【按】** 上论元神、忌神之有力、无力者，亦要用神有气。倘若用神无根，谓之元神有力亦难生，忌神无力亦休喜。
