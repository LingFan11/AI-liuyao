## 一、月破章

### 1.1 月破基本定义

**原文**：
正申，二酉，三戌，四亥，五子，六丑，七寅，八卯，九辰，十巳，十一午，十二未。

月建冲之为月破，逐月之破日，是也。

**注释**：
- 月建冲之为月破：月建所冲的地支为月破
- 逐月之破日：每个月都有破日（月建相冲之日）
- 如正月建寅，申日为破日；二月建卯，酉日为破日

**月破配对表**：

| 月份 | 月建 | 月破地支 | 说明 |
|------|------|----------|------|
| 正月 | 寅 | 申 | 寅申相冲 |
| 二月 | 卯 | 酉 | 卯酉相冲 |
| 三月 | 辰 | 戌 | 辰戌相冲 |
| 四月 | 巳 | 亥 | 巳亥相冲 |
| 五月 | 午 | 子 | 午子相冲 |
| 六月 | 未 | 丑 | 未丑相冲 |
| 七月 | 申 | 寅 | 申寅相冲 |
| 八月 | 酉 | 卯 | 酉卯相冲 |
| 九月 | 戌 | 辰 | 戌辰相冲 |
| 十月 | 亥 | 巳 | 亥巳相冲 |
| 十一月 | 子 | 午 | 子午相冲 |
| 十二月 | 丑 | 未 | 丑未相冲 |

**现代白话解释**：

**月破**：指卦爻的地支被月建所冲，称为月破。

**判断方法**：
- 看占卜时的月建（月份对应的地支）
- 月建冲卦中某爻，该爻即为月破
- 如正月寅月，卦中有申金爻，申金被寅木冲，即为月破

**月破的特点**：
月破是六爻中非常重要的概念，古今断法有很大争议。

### 1.2 古法月破论

**原文**：
诸书皆以用神临月破，谓之"悖时"，如枯根朽木，逢生生之不起，逢伤伤者更重。虽现于卦，有亦如无；伏于卦中，终难透露。即有日辰之生，亦不能生。动而作忌神者，亦不能为害，作变爻者，亦不能伤克动爻。

**现代白话解释**：

**古法观点（《易冒》《易林补遗》等）**：

用神临月破，谓之"悖时"（违背时令），如同枯根朽木：

1. **逢生生之不起**：即使日辰、动爻来生，也生不起来
2. **逢伤伤者更重**：如果被克制，伤害更重
3. **虽现于卦，有亦如无**：虽然出现在卦中，等于没有
4. **伏于卦中，终难透露**：如果伏藏，永远难以显现
5. **日辰之生，亦不能生**：日辰生扶也无用
6. **动而作忌神者，亦不能为害**：动爻作忌神，也不能为害
7. **作变爻者，亦不能伤克动爻**：作为变爻，也不能克制动爻

**总结**：古法认为月破=无用，百无一用。

### 1.3 野鹤新论

**原文**：
野鹤曰：余得其验，动则能伤于爻，变则能伤于动，何也？神兆机于动，事之无吉无凶则不动矣。既动，则有祸福之基。目下虽破，出月则不破。今日虽破，实破之日则不破，逢合之日则不破，近应日时，远应年月。惟静而不动，又无日辰动爻生助，实则到底而破矣。

**现代白话解释**：

**野鹤观点（《增删卜易》作者）**：

作者通过大量实战验证，发现古法不准确。**月破爻如果发动，仍然有用**：

1. **动则能伤于爻**：月破爻发动，仍能克制其他爻
2. **变则能伤于动**：月破爻作变爻，仍能克制动爻
3. **神兆机于动**：神机在于动，既然动了，就有原因
4. **出月则不破**：过了这个月，就不再月破
5. **实破之日则不破**：到了填实月破的日子，就不破了
6. **逢合之日则不破**：月破逢合的日子，也不破了
7. **近应日时，远应年月**：近期应验在日时，远期应验在年月

**关键判断**：
- **月破爻发动**：有用，能克制其他爻，只是力量减弱
- **月破爻静止，无生助**：到底而破，确实无用

**应期**：
- **出月**：过了月破的月份
- **实破之日**：填实月破的日子（如申金月破，逢申日）
- **逢合之日**：与月破爻相合的日子（如申金月破，逢巳日，巳申合）

### 1.4 月破实战卦例

#### 例一：占将来有官否（兑之讼）

**如：亥月己丑日（旬空：午未），占将来有官否？得"兑之讼"**

**本卦：兑宫兑为泽（六冲）**
```
勾陈              父母丁未土  ━ ━ 世  ×→
朱雀              兄弟丁酉金  ━━━
青龙              子孙丁亥水  ━━━
玄武              父母丁丑土  ━ ━ 应
白虎              妻财丁卯木  ━━━
螣蛇              官鬼丁巳火  ━━━     ○→
```

**变卦：离宫天水讼（游魂）**
```
父母壬戌土  ━━━
兄弟壬申金  ━━━
官鬼壬午火  ━━━ 世
官鬼戊午火  ━ ━
父母戊辰土  ━━━
妻财戊寅木  ━ ━ 应
```

**解析**：
- 占官：以官鬼爻为用神
- 用神：官鬼巳火发动，生世爻
- 世爻：未土持世发动化戌土（进神）
- 月破：官鬼巳火逢亥月月破
- 旬空：世爻未土旬空（午未空）

**断曰**：此卦官动而生世，世动化进神，显然有官之象。但官逢月破，世遇旬空，然此空犹有日辰相冲，冲空则实，不为空矣。而此破又无日辰动爻之生，古以日建亦生之不起，况无动爻日建以生乎？余疑之，既无所用，何故动而生世？命之再占。

**再占：水地比（归魂）**
```
坤宫：水地比（归魂）
勾陈              妻财戊子水  ━ ━ 应
朱雀              兄弟戊戌土  ━━━
青龙              子孙戊申金  ━ ━
玄武              官鬼乙卯木  ━ ━ 世
白虎              父母乙巳火  ━ ━
螣蛇              兄弟乙未土  ━ ━
```

**综合判断**：
命若无官，如何得官来生世，及官星以持世也？今既前卦动官相生，后得官临世位，食禄王家，终须有日。彼问应在何年？余曰：前卦官临月破，定在实破之年。

**应验**：果于巳年承袭长房世职。

**理论验证**：
- 前卦巳火官鬼月破（亥月），但发动生世，说明有官
- 后卦官鬼持世，确认有官
- 应期在巳年，即**实破之年**（填实月破）
- 若以月破为百无所用，岂不失之千里？

**现代白话解释（包括解析、断曰和应验）**：
1. **月破爻发动有用**：官鬼巳火虽逢亥月月破，但发动生世，说明有官之象。古法认为月破百无所用，但野鹤认为"神兆机于动"，动则有因。
2. **世爻旬空出空则实**：世爻未土旬空（午未空），但日辰丑日冲之，冲空则实，不为空矣。
3. **疑而再占**：月破又无日辰动爻之生，古以日建亦生之不起。既无所用，何故动而生世？野鹤疑之，命再占。
4. **两卦互证**：前卦官动生世，后卦官临世位，两卦互证，必有官禄。
5. **应期在实破之年**：官临月破，定在实破之年（巳年）。果于巳年承袭长房世职。
6. **验证野鹤新论**：月破爻发动仍有用，应期在实破之年、出月之时，验证野鹤突破古法之正确性。

#### 例二：占父何日归（乾之夬）

**如：辰月戊子日（旬空：午未），占父何日归，得"乾之夬"**

**本卦：乾宫乾为天（六冲）**
```
朱雀              父母壬戌土  ━━━ 世  ○→
青龙              兄弟壬申金  ━━━
玄武              官鬼壬午火  ━━━
白虎              父母甲辰土  ━━━ 应
螣蛇              妻财甲寅木  ━━━
勾陈              子孙甲子水  ━━━
```

**变卦：坤宫泽天夬**
```
父母丁未土  ━ ━
兄弟丁酉金  ━━━ 世
子孙丁亥水  ━━━
父母甲辰土  ━━━
妻财甲寅木  ━━━ 应
子孙甲子水  ━━━
```

**解析**：
- 占父归期：以父母爻为用神
- 用神：父母戌土持世发动
- 动化：戌土动化未土（旬空）
- 月破：戌土逢辰月月破（辰戌相冲）
- 无生助：既无日生，又无动助

**古法断**：父母持世，破而化空，既无日生，又无动助，以古法断，作用神无气，其父不能归也。

**野鹤断**：余不以此断，竟决以朱雀临父，动而持世，卯日有信，午未日必归。

**应验**：
- 果于卯日得信
- 乙未日抵家

**应期原理**：
- **卯日得信**：破而逢合之日（卯戌合）
- **未日归家**：父化未土旬空，出空之日而到

**理论辨析**：
古法进神之论，谓之动逢月破，我位既失，化月建，亦为退之不及。此卦父爻破而化空，竟退以归家。

**现代白话解释（包括解析、断曰和应验）**：
1. **月破化空无生助**：父母戌土持世发动，逢辰月月破，化未土旬空，既无日生，又无动助。
2. **古法断不能归**：按古法，作用神无气，其父不能归。
3. **野鹤不以古法断**：朱雀临父，动而持世，虽月破化空，神兆机于动，动必有因。
4. **破而逢合之日**：卯日卯戌合，破而逢合，有信至。
5. **出空之日必归**：未日父化未土出空，出空之日而到。
6. **应验精准**：果于卯日得信，乙未日抵家。
7. **验证野鹤新论**：月破爻发动仍有用，破而逢合、出空之日可成事。古法"动逢月破退之不及"，但此卦父爻破而化空，竟退以归家，验证野鹤理论之正确。

**本卦：艮宫艮为山（六冲）**

```
白虎              官鬼丙寅木  ━━━ 世

朱雀              子孙丙申金  ━━━ 应  ○→
青龙              父母丙午火  ━ ━
玄武              兄弟丙辰土  ━ ━
```

**变卦：乾宫风地观**
```
官鬼辛卯木  ━━━
父母辛巳火  ━━━
兄弟辛未土  ━ ━ 世
官鬼乙卯木  ━ ━
父母乙巳火  ━ ━
兄弟乙未土  ━ ━ 应
```

**解析**：
- 占功名：以官鬼爻为用神
- 世爻：寅木官星持世
- 动爻：申金动克世，子水动生世
- 月破：子水逢午月月破
- 化空：子水化巳火旬空（辰巳空）

**断曰**：
寅木官星持世，被申金动而克之，今年七月必有凶非。彼问：看因何事？余曰：应动而克世，必系仇家。又问："于功名碍否？"余曰：若非子水动摇，去位必矣，幸有子水接续相生，降级离任而不免耳。

次日幕客问："既知子水接续相生，卜书有曰：忌神与元神同动，官与世爻得两生也。今冬高升之兆，如何反说离任？"余曰：**子水破而化空，卜书有曰："虽有如无。"作元神而无用。** 余今不以古法断者，盖**神兆机于动，动必有因，所以只断之降调而已**。依在下之断，若在冬至月，始有此验，倘在他月，子水而未实破，还不可知。

**应验第一次**：
果于七月，彼此揭参而成大非，至冬至月事结，降级调用。

**再占：地泽临**

**如：寅月丙辰日（旬空：子丑），复占得"地泽临"**

```
坤宫：地泽临
青龙              子孙癸酉金  ━ ━
玄武              妻财癸亥水  ━ ━ 应
白虎              兄弟癸丑土  ━ ━
螣蛇              兄弟丁丑土  ━ ━
勾陈              官鬼丁卯木  ━━━ 世
朱雀              父母丁巳火  ━━━
```

**解析**：
- 官鬼卯木持世
- 六五亥水生官
- 日辰丙辰克亥水

**断曰**：
余曰：近闻士民保留，恐不允，必待子年仍以原品起用。幕客问："六五亥水生官，如何不允？"余曰：**六五来生，今被日克，将来子年，亥水旺于子也，又合前卦，五爻之子水值太岁而不破，起用无疑。**

**应验第二次**：
果于甲子年巳月，仍以原品起用，连补两任，卯年而开督府。

**劝辞荣**：
余劝辞荣。彼曰：何也？余曰：仍以前卦决之耳。向因申金克世，子水虽动，临破化空，不能生世生官，所以成非构怨。及至子月，虽则实破，其力尚微，虽不至于削职，犹有降调之事。**后值子岁，乃实破之年也，值太岁当权，是以起用。明年辰岁，又是子水入墓之年，太岁克去子水，申金仍复克世，有克无生，较昔年之祸更重。**

不听。

**应验第三次**：
果于辰年三月条陈，虽留万世芳名，而得罪解任矣。

**理论总结**：
以上之辨月破者，**乃因破而动也，不动，勿以此断**。

**现代白话解释（包括解析、断曰和三次应验）**：
1. **卦象分析**：官鬼寅木持世，申金动克世，子水月破化空动生世。
2. **第一次应验-七月成非**：申金克世，七月必有凶非，系仇家所害。
3. **子水破而化空**：子水元神虽动，但临破化空，卜书云"虽有如无"。野鹤不以古法断，神兆机于动，动必有因，只断降调而已。
4. **冬至月降调**：果于七月彼此揭参成大非，至冬至月（子月）事结，降级调用。子月虽实破，其力尚微。
5. **再占地泽临**：官鬼卯木持世，六五亥水生官，但被日辰克。待子年亥水旺于子，又合前卦五爻子水值太岁不破，起用无疑。
6. **第二次应验-子年起用**：果于甲子年巳月，仍以原品起用，连补两任，卯年而开督府。值子岁，乃实破之年，太岁当权是以起用。
7. **劝辞不听**：野鹤劝辞荣。明年辰岁，又是子水入墓之年，太岁克去子水，申金仍复克世，有克无生，较昔年之祸更重。
8. **第三次应验-辰年解任**：果于辰年三月条陈，虽留万世芳名，而得罪解任矣。
9. **核心理论**：月破爻发动仍有用。子月实破力微有降调，子年实破当权而起用，辰年入墓得祸更重。半生凶吉，关乎一爻之月破，岂可谓之毫无所用？验证"破而动也"之论，不动勿以此断。

### 1.5 月破理论辨析

**李我平评论**：

李我平曰：《易冒》之论月破，动作忌神而无害，动作元神而无用，日辰生之而不起，百无所用之卦也。《易林补遗》也曰：如临月破之爻，不拘衰旺，概作凶推。逢生不生，遇克能伤，亦曰虽有如无也。

观此艮之观卦，占时而值月破，不能接续相生。王庭构讼，值月建以填实，其力尚轻，犹有降罚之事。值太岁而当权，仍以原品而起用。至辰年而入墓，得祸匪轻。半生凶吉，关乎一爻之月破。**岂可谓之有亦如无，毫无所用耶？！**

**现代白话解释**：

李我平通过分析"艮之观"卦例，得出结论：
1. **月破非无用**：月破爻发动仍有作用
2. **应期关键**：
   - 值月建填实，力尚轻，有降罚
   - 值太岁当权，原品起用
   - 至辰年入墓，得祸匪轻
3. **半生吉凶，关乎一爻月破**：不可谓月破毫无所用

## 二、飞伏神章

### 2.1 飞伏神基本定义

**原文**：
凡卦，用神不现者，即以日月为用神。倘日月非用神，须于本宫首卦寻之。盖本宫之首卦六亲俱全之故耳。

**现代白话解释**：

**什么是飞伏神**：
当卦中没有所需的用神时（用神不上卦），需要寻找伏神：

1. **首选**：如果日月就是用神，直接以日月为用神
2. **次选**：如果日月不是用神，须到本宫首卦中寻找伏神

**为什么到本宫首卦寻找**：
因为本宫首卦（八纯卦）六亲俱全，任何六亲都能找到。

**飞神与伏神**：
- **伏神**：隐藏在卦爻下面的用神（本宫首卦中对应的爻）
- **飞神**：卦中显现的爻，在伏神的上面

**示例一：占妻财（天风姤卦）**

**如：占得"天风姤"卦**
```
乾宫：天风姤
              父母壬戌土  ━━━
              兄弟壬申金  ━━━
              官鬼壬午火  ━━━ 应
              兄弟辛酉金  ━━━
  妻财甲寅木   子孙辛亥水  ━━━
              父母辛丑土  ━ ━ 世
```

**伏神寻找**：
- 占妻财，取财爻为用神
- 姤卦系乾宫之卦，以寅卯木爻为妻财
- 六爻并无寅卯木，用神不上卦
- 如在寅卯月日占，则以日月为用神
- 如非寅卯月日，须在本宫首卦"乾为天"中寻之

**【按】** 乾卦寅木妻财在二爻，即以此寅木妻财伏于姤卦亥水之下，姤卦二爻之亥水为飞神，寅木即为伏神，亥水而生寅木，谓之"**飞来生伏得长生**"。此乃用神不现，寻得伏神而遇生扶，无用亦为有用，便作吉断。余仿此。

**示例二：占子孙（天山遁卦）**

**如：占得"天山遁"卦**

- 如在亥子月日占，则以日月为用神
- 如非亥子月日，须在本宫首卦"乾为天"中寻之

**【按】** 乾卦子水子孙在初爻，即以此子水子孙伏于遁卦辰土之下，遁卦初爻之辰土，即是飞神，子水便是伏神，辰土而克子水，谓之"**飞来克伏遭克害**"，名为伏神受制，有用亦无用矣，即以凶推。余仿此。

### 2.2 伏神有用六法

**原文**：
伏神有用者六：
- 伏神得日月生者，一也。
- 伏神旺相者，二也。
- 伏神得飞神生者，三也。
- 伏神得动爻生者，四也。
- 伏神得遇日月动爻冲克飞神者，五也。
- 伏神得遇飞神空破休囚墓绝者，六也。

此六者，皆有用之伏神也，虽曰不现，亦如现矣。

**现代白话解释**：

**伏神有用的六种情况**：

**1. 伏神得日月生**：
- 伏神虽伏藏，但得日辰或月建生扶
- 如木伏神得亥子水日月生

**2. 伏神旺相**：
- 伏神本身处于旺相之地
- 如木伏神在春天，金伏神在秋天

**3. 伏神得飞神生**：
- 飞神生扶伏神（飞来生伏）
- 如亥水飞神生寅木伏神

**4. 伏神得动爻生**：
- 卦中动爻生扶伏神
- 如卦中有水爻动来生木伏神

**5. 伏神得遇日月动爻冲克飞神**：
- 日月或动爻冲克飞神，解放伏神
- 如辰土飞神被日月或动爻冲克

**6. 伏神得遇飞神空破休囚墓绝**：
- 飞神空亡、月破、休囚、入墓、临绝
- 飞神无力压制，伏神易出

**《黄金策》曰**：
"空下伏神，易于引拔。"此论近理，但又不独飞神空亡而伏神得出，但得飞神临破、临绝、休囚、入墓，而伏神皆易出也。何也？伏神在下，飞神在上，飞神既逢破墓衰空，虽有如无，所以伏神易于出现。

**现代白话解释（《黄金策》论述）**：
1. **空下伏神易出**：《黄金策》说"空下伏神，易于引拔"，意思是飞神旬空，伏神容易出现。这个论述很有道理。
2. **不独空亡**：但不仅仅飞神空亡伏神才能出，只要飞神临月破、临绝地、休囚无气、入墓，伏神都容易出现。
3. **原理解释**：为什么呢？伏神在下面，飞神在上面压制。飞神既然遇到破墓衰空，虽有如无，所以伏神容易出现，不再被压制。
4. **实战应用**：判断伏神能否出现，关键看飞神的状态。飞神越弱，伏神越容易出现。

### 2.3 伏神无用五法

**原文**：
伏神终不得出者五：
- 伏神休囚无气者，一也。
- 伏神被日月冲克者，二也。
- 伏神被旺相之飞神克害者，三也。
- 伏神墓绝于日月飞爻者，四也。
- 伏神休囚，值旬空月破者，五也。

此五者，乃无用之伏神也，虽有如无，终不能出。

**现代白话解释**：

**伏神无用的五种情况**：

**1. 伏神休囚无气**：
- 伏神处于休囚死绝之地
- 如木伏神在秋冬，金伏神在春夏

**2. 伏神被日月冲克**：
- 日辰或月建冲克伏神
- 如木伏神被申酉金日月克

**3. 伏神被旺相之飞神克害**：
- 飞神旺相，克制伏神（飞来克伏）
- 如辰土飞神旺相，克子水伏神

**4. 伏神墓绝于日月飞爻**：
- 伏神入日月之墓，或临绝地
- 如木伏神入未墓、临申绝

**5. 伏神休囚，值旬空月破**：
- 伏神休囚，又逢旬空或月破
- 雪上加霜，彻底无用

**《黄金策》辨析**：
《黄金策》曰："伏居空地，事与心违。"余得验者，非此论也，凡用神旺相而遇旬空，出空之日则出矣。

**现代白话解释（《黄金策》辨析）**：
1. **《黄金策》的观点**：《黄金策》说"伏居空地，事与心违"，认为伏神旬空，事情就不能如愿。
2. **野鹤的实战验证**：我的实战验证结果，不是这样的！只要用神旺相而遇旬空，出空之日就能出现。
3. **关键在旺衰**：伏神旬空不一定无用，关键看伏神本身是否旺相。旺相的伏神即使旬空，出空之日仍有用。休囚的伏神旬空，那才真是无用。
4. **理论突破**：不能一见旬空就断无用，要结合旺相休囚综合判断。这是野鹤对《黄金策》理论的重要突破。

### 2.5 飞伏神理论辨析

**李我平评论**：

李我平曰：古法用伏神虽则有验，然伏神之衰旺休囚、刑冲克害、月破旬空，亦有难于把握者。此言多占两卦，自有用神，真秘法也。以此之秘，急欲传世，真婆心也！

或曰：多占两卦，虽有渎之，不敢再三。然而亦有再占者，何为秘诀？余曰：既知再占，何必用神不现而寻伏神，伏神无用又寻互卦，互之不得又寻干化？况《易冒》变互章中所存占验，未免牵强，且错误颇多。

**现代白话解释（李我平评论）**：
1. **肯定多占法**：李我平评价说，古法用伏神虽然有验证，但伏神的衰旺休囚、刑冲克害、月破旬空，实在难于把握。野鹤提出多占两卦，用神自然显现，这才是真秘法！以此秘法急欲传世，真是婆心（慈悲心肠）！
2. **有人质疑**：有人说多占两卦，虽有渎（亵渎神灵），不敢再三再四地占。但既然可以再占，为何要纠结于伏神？
3. **野鹤反驳**：既然知道可以再占，何必用神不现就去寻伏神？伏神无用又去寻互卦？互卦找不到又去寻干化（天干化合）？《易冒》变互章中的占验案例，未免牵强附会，且错误颇多。
4. **核心观点**：不要舍近求远，简单明了的多占法远胜于复杂难懂的伏神法、互卦法、干化法。
